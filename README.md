# Cassava Leaf Disease Classification

A deep learning-based image classification project for identifying
cassava leaf diseases using EfficientNetB3 transfer learning.

## Problem Statement

Cassava is an important food crop, and leaf diseases can significantly
affect crop production. This project uses computer vision and deep
learning to classify cassava leaf images into different disease categories.

## Disease Classes

The model classifies images into:

- Cassava Bacterial Blight (CBB)
- Cassava Brown Streak Disease (CBSD)
- Cassava Green Mottle (CGM)
- Cassava Mosaic Disease (CMD)
- Healthy

## Approach

1. Image preprocessing
2. Data augmentation
3. EfficientNetB3-based transfer learning
4. Model fine-tuning
5. Multi-class classification
6. Model evaluation
